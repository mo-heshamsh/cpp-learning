## 🌟 featured project: mo's mini market

a full-featured terminal shopping application built completely from scratch in c++.

### 🔑 key features:
* **user authentication & security:** login system with username/password validation and limited login attempts.
* **inventory & cart management:** browse live store stock, add items to cart, track remaining inventory, and calculate total bills.
* **flexible checkout system:** supports **cash**, **visa**, and **vodafone cash** payment methods with real-time balance deductions.
* **account balance overview:** dedicated view option to check remaining funds across all payment types.
* **robust input normalization:** string case-insensitivity using `tolower()` and division-by-zero checks.
* and many more!
