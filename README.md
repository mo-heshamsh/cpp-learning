## 🌟 Featured Project: Mo's Mini Market V3 (C++)

A full-featured terminal shopping application built completely from scratch in C++.

* 🔑 **Key Features:**
  * **Authentication:** Login system with username/password validation and attempt limits.
  * **Inventory & Cart:** Live store stock, cart management, and real-time total calculations.
  * **Payment System:** Supports Cash, Visa, and Vodafone Cash with balance tracking.
  * **Robust Logic:** Case normalization using `tolower()` and defensive input handling.
